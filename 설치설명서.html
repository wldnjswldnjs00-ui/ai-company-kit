AI 본사 — 24시간 일하는 AI 부서

버전 1.0 · 새 버전을 받으셨다면 👉 아래 🔄 업데이트 받는 법 부분부터 보세요.

비서실, 마케팅, 고객지원, 재무, 법무 같은 AI 부서가 24시간 회사 일을 합니다. 사장님은 텔레그램으로 지시하고, 보고를 받고, 결재 버튼만 누르면 됩니다.

  • 월 0원부터 시작합니다(무료 한도 안에서). 더 똑똑하게 쓰고 싶으면 값 3개만 넣어 유료 두뇌(Claude)로 업그레이드할 수 있습니다.
  • 쌓인 회사의 기억은 사장님 것입니다. 두뇌를 바꿔도 그대로 이어지고, 언제든 파일로 가져갈 수 있습니다.
  • 설치는 약 30분, 개발 지식이 없어도 됩니다. 설치 화면이 단계마다 ✅/❌ 와 고치는 방법을 알려 줍니다.

⚠️ 알아 두세요

  • 무료 두뇌(Google Gemini)는 하루 사용량에 한도가 있습니다. 한도를 넘으면 일이 다음 날로 밀립니다. 멈추지는 않습니다.
  • Gemini 무료 사용분은 입력 내용이 Google 서비스 개선에 쓰일 수 있습니다. 그래서 이메일·전화번호·계좌 같은 개인정보는 자동으로 가린 뒤 보냅니다. 그래도 영업 비밀은 넣지 마세요. 민감한 일이 많다면 유료 두뇌를 쓰세요.
  • AI 는 돈을 쓰거나, 고객에게 연락하거나, 외부에 글을 올리지 않습니다. 그런 일은 항상 사장님 결재로 올라옵니다.

💡 자율 제안 매일 부서들이 스스로 문제점과 개선안을 찾아 ✅승인 · ⏸보류 · ❌거절 버튼과 함께 올립니다.

🧠 회사의 기억 일할 때마다 배운 점, 사장님의 결정과 피드백이 쌓입니다. 시간이 갈수록 우리 회사에 맞게 일합니다.
⚖️ 법무팀 · 🔭 미래전략팀 답하기 전에 매번 인터넷에서 최신 자료를 검색하고 출처를 붙입니다.
🔎 웹사이트순찰팀 진짜 브라우저로 우리 웹사이트를 휴대폰 화면으로 열어 보고, 오류·어색한 점을 찾습니다.
📑 보고 매일 21시 일일 보고, 매월 1일 월간 경영 보고서(인쇄/PDF 가능).

부서는 설치할 때 고릅니다: 운영, 고객지원, 마케팅, 영업, 재무, 데이터분석, 기획, 법무, 미래전략, 웹사이트순찰, 인사, 감사실. 부서 이름·사명·일하는 방식은 설치 후 대시보드에서 우리 회사에 맞게 고칠 수 있습니다.

설치하기 (30분)

준비물: 이메일 주소, 휴대폰(텔레그램). 모든 가입은 무료입니다.

1단계. 계정 4개 만들기 (10분)

서비스 하는 일 가입
GitHub 이 프로그램을 보관 github.com
Cloudflare 24시간 돌아가는 서버 dash.cloudflare.com
Supabase 회사의 기억을 저장 supabase.com
Google AI Studio AI 두뇌 열쇠 aistudio.google.com

그리고 휴대폰에 텔레그램 앱을 설치하세요.

2단계. 프로그램을 내 GitHub 에 올리기 (3분, PC 에서)

  1. 받은 ZIP 파일의 압축을 풉니다. 폴더 안에 src, supabase, package.json 등이 보이면 됩니다.
  2. github.com → 오른쪽 위 ＋ → New repository.
  3. Repository name 에 my-ai-company 처럼 아무 이름을 넣고, Private 을 고른 뒤 Create repository 를 누릅니다.
  4. 다음 화면 가운데의 uploading an existing file 링크를 누릅니다.
  5. 압축 푼 폴더 안의 모든 파일과 폴더를 선택해서 브라우저 창에 끌어다 놓습니다(폴더째가 아니라 폴더 안의 것들).
  6. 올라가기를 기다렸다가 아래 초록색 Commit changes 를 누릅니다.

GitHub 저장소로 초대받았다면 1~6 대신, 그 저장소의 Use this template → Create a new repository(Private) 를 누르면 됩니다.

3단계. Cloudflare 에 올리기 (3분)

  1. dash.cloudflare.com → 왼쪽 Workers & Pages → Create → Import a repository 를 누릅니다.
  2. GitHub 를 연결하고, 방금 만든 저장소를 고릅니다.
  3. 아무것도 바꾸지 말고 Deploy 를 누릅니다.
    • 처음 쓰는 계정이면 workers.dev 주소 앞부분(예: mybakery)을 정하라고 나옵니다. 영어로 아무 이름이나 정하세요.
  4. 1~2분 뒤 배포가 끝나면 대시보드 주소가 생깁니다. 모양은 이렇습니다: https://ai-company.mybakery.workers.dev
  5. 주소 찾는 곳: Cloudflare → Workers & Pages → 방금 만든 Worker 이름을 누르면, 화면 위쪽 Domains & Routes(또는 Visit 버튼)에 있습니다. 눌러서 열리면 성공입니다.
    • 이 주소는 나만 쓰는 대시보드입니다. 즐겨찾기해 두세요. 잊어버려도 나중에 텔레그램에서 /check 를 보내면 알려 줍니다.

4단계. Supabase 준비 (5분)

  1. supabase.com → New project → 이름과 비밀번호를 넣고 Create new project. (Region 은 Northeast Asia (Seoul) 을 추천합니다.)
  2. 1~2분 뒤 프로젝트가 준비되면 왼쪽 SQL Editor → New query 를 누릅니다.
  3. 이 저장소의 supabase/setup.sql 파일을 열어 전체를 복사해서 붙여 넣고 Run 을 누릅니다. Success 가 나오면 됩니다.

5단계. 값 5개 넣기 (7분)

Cloudflare → Workers & Pages → 내 Worker → Settings → Variables and Secrets → Add 를 눌러 아래 5개를 넣습니다. 종류(Type)는 모두 Secret 으로 고르세요.

이름 (그대로 복사) 값을 가져오는 곳
SUPABASE_URL Supabase → Project Settings → Data API → Project URL (https://xxxx.supabase.co)
SUPABASE_SECRET_KEY Supabase → Project Settings → API Keys → Secret key (sb_secret_…)
GEMINI_API_KEY aistudio.google.com → Get API key → Create API key
TELEGRAM_BOT_TOKEN 텔레그램에서 @BotFather 검색 → /newbot → 봇 이름 두 번 입력 → 받은 토큰 전체 (123456:ABC…)
DASHBOARD_PASSWORD 대시보드 로그인 비밀번호. 직접 정해서 넣고 꼭 메모해 두세요.

Deploy(또는 Save)를 누르고 1분 기다립니다.

6단계. 설치 화면에서 마무리 (5분)

  1. 3단계에서 찾은 대시보드 주소(https://….workers.dev)를 열고, DASHBOARD_PASSWORD 로 로그인합니다.
  2. 설치 화면이 나옵니다. 위에서부터 차례로 하세요.
    • 기본 연결: 5단계의 값이 맞는지 자동으로 확인합니다. ❌ 가 있으면 아래 설명대로 고치고 새로고침하세요.
    • 회사 소개: 우리 회사가 무엇을 하는지 적습니다. 구체적일수록 결과가 좋습니다.
    • 부서 고르기: 추천이 미리 체크되어 있습니다. 웹사이트가 있으면 주소도 넣으세요.
    • 텔레그램 연결: 봇 연결하기 를 누르고, 화면에 나온 /start 123456 을 내 봇에게 보냅니다.
    • 🎨 로고와 메뉴 색 (선택): 우리 회사 로고를 올리고, 왼쪽 메뉴를 블랙 또는 화이트로 고릅니다. 아래 🎨 로고와 메뉴 색 바꾸기 를 보세요.
  3. 모두 ✅ 가 되면 대시보드로 가기 를 누릅니다. 끝입니다! 🎉

텔레그램으로 "이번 달 할 일 정리해줘" 처럼 말해 보세요.

📱 휴대폰 홈 화면에 앱처럼 추가하기 (1분)

대시보드를 휴대폰 홈 화면에 추가하면 앱처럼 아이콘을 눌러 바로 열 수 있습니다. 앱 스토어 설치는 필요 없습니다.

아이폰 (Safari)

  1. Safari 로 대시보드 주소를 엽니다. (다른 브라우저에서는 이 메뉴가 없을 수 있습니다.)
  2. 화면 아래 가운데 공유 버튼(네모에서 화살표가 위로 나온 모양 ⬆️)을 누릅니다.
  3. 목록을 아래로 내려 홈 화면에 추가 를 누릅니다.
  4. 이름을 확인하고 오른쪽 위 추가 를 누릅니다.

갤럭시 (삼성 인터넷)

  1. 삼성 인터넷 으로 대시보드 주소를 엽니다.
  2. 화면 아래 오른쪽 메뉴(줄 세 개 ☰)를 누릅니다.
  3. 현재 페이지 추가 → 홈 화면 을 누릅니다.
  4. 추가 를 누릅니다.

갤럭시 (크롬)

  1. 크롬 으로 대시보드 주소를 엽니다.
  2. 오른쪽 위 점 세 개 ⋮ 를 누릅니다.
  3. 홈 화면에 추가(또는 앱 설치)를 누르고, 추가 를 누릅니다.

로그인은 한 번 하면 30일 동안 유지됩니다. 아이콘을 바꾸고 싶으면 설정 화면에서 앱 아이콘을 올린 뒤, 홈 화면의 아이콘을 지우고 다시 추가하세요.

🎨 로고와 메뉴 색 바꾸기

대시보드 왼쪽 메뉴의 설정 → 로고와 메뉴 색. 컴퓨터에서는 왼쪽 위 로고에 마우스를 올리면 나오는 연필 버튼으로 바로 갈 수 있습니다.

칸 무엇을 올리나
왼쪽 메뉴 색 ⬛ 블랙 또는 ⬜ 화이트
밝은 배경용 로고 검은색·진한 글씨 로고. 화이트 메뉴에 쓰입니다.
어두운 배경용 로고 흰색·밝은 글씨 로고. 블랙 메뉴에 쓰입니다.
앱 아이콘 휴대폰 홈 화면 아이콘. 정사각형(512×512 추천).
  • 전부 선택입니다. 로고를 안 올리면 회사 이름이 글자로 나옵니다. 로고가 하나뿐이어도 어느 메뉴 색에서나 잘 보이게 자동으로 받침을 깔아 줍니다.
  • PNG·JPG·WebP, 한 장에 300KB 이하. 배경이 투명한 PNG 가 가장 깔끔합니다.
  • 회사 이름을 바꾸려면 같은 화면의 회사 소개 에서 고치세요. 탭 이름과 홈 화면 이름도 함께 바뀝니다.

  • 더 깊고 정확한 보고서를 원하는 분
  • 무료 AI 에 넣은 내용이 서비스 개선에 쓰일 수 있는 점이 걱정되는 분 (유료 두뇌의 데이터 정책은 Anthropic 약관을 확인하세요)

유료 두뇌는 Anthropic 의 Claude 를 씁니다. 프로그램은 이미 준비되어 있어서, 값 3개만 넣으면 바로 바뀝니다. 코드를 고칠 필요가 없습니다.

바꾸는 방법 (10분)

  1. console.anthropic.com 에 가입합니다. (Claude 채팅 구독과는 별개의 개발자용 계정입니다)
  2. Billing(결제) 메뉴에서 크레딧을 충전합니다. 예: 20달러.
    • 충전한 금액까지만 쓰입니다. 크레딧이 떨어지면 자동으로 무료 두뇌로 돌아가서, 요금이 몰래 늘어나지 않습니다.
  3. API Keys 메뉴 → Create Key 로 열쇠를 만들고 복사합니다. (sk-ant-… 로 시작)
  4. Cloudflare → 내 Worker → Settings → Variables and Secrets 에 아래 값을 넣고 Deploy 를 누릅니다.
이름 값 설명
BRAIN_PROVIDER claude 유료 두뇌 켜기. free 로 바꾸면 다시 무료로 돌아갑니다
ANTHROPIC_API_KEY 3번에서 복사한 열쇠 Secret 으로 넣으세요
CLAUDE_DAILY_LIMIT 예: 30 하루 최대 사용 횟수. 한 달 비용의 상한이 됩니다
CLAUDE_MODEL (선택) claude-sonnet-5-5 비용을 절반으로 줄이고 싶을 때. 넣지 않으면 가장 똑똑한 claude-opus-5-5 를 씁니다
  1. 텔레그램에서 /check 를 보내면 "🧠 두뇌: 유료 Claude" 로 바뀐 것을 확인할 수 있습니다.

한 달에 얼마나 드나요?

CLAUDE_DAILY_LIMIT 을 다 쓴다고 가정한 최대 금액입니다. (1달러 약 1,400원, 보고서 길이에 따라 달라짐)

하루 한도 Opus (가장 똑똑함, 1회 약 160원) Sonnet (절반 가격, 1회 약 80원)
30회 월 최대 약 14만 원 월 최대 약 7만 원
60회 월 최대 약 29만 원 월 최대 약 14만 원
90회 월 최대 약 43만 원 월 최대 약 22만 원
  • 부서 56개를 쓰는 작은 회사라면 **하루 3060회**면 대부분 충분합니다.
  • 한도를 다 쓴 날은 무료 두뇌가 이어받아 일이 멈추지 않습니다.
  • 사용량은 대시보드 성과 메뉴의 "두뇌 사용량"에서 볼 수 있습니다.

🧠 회사의 기억은 사장님 것입니다

AI 가 일하면서 쌓은 것(배운 점, 사장님의 결정과 피드백, 대응 매뉴얼, 모든 보고서)은 AI 회사가 아니라 사장님의 Supabase 에 저장됩니다.

  • 두뇌를 바꿔도 기억은 그대로입니다. 무료(Gemini) → 유료(Claude)로 바꾸거나, 나중에 더 좋은 AI 가 나와 바꿔도, 쌓인 기억을 그대로 이어서 씁니다.
  • 언제든 파일로 가져갈 수 있습니다. 대시보드 기억 메뉴 → 📥 전체 기억 파일로 받기. 사람이 읽을 수 있는 문서(.md) 파일이라, ChatGPT·Claude 같은 다른 AI 에 그대로 붙여 넣어 "우리 회사는 이런 곳이야"라고 알려 줄 수도 있습니다.
  • 매주 자동 백업됩니다. 일요일 20시마다 전체 기억 파일이 텔레그램으로 옵니다.
  • 보고서도 전부 남습니다. 보고서마다 파일(.md)로 받거나 인쇄/PDF 로 저장할 수 있습니다.

🔄 업데이트 받는 법

AI 본사는 가끔 새 버전이 나옵니다. 이미 구매하셨다면 추가 비용 없이 새 파일을 받으실 수 있습니다.

내 버전 확인

  • 대시보드 왼쪽 메뉴 맨 아래 에 AI 본사 1.0 처럼 나옵니다.
  • 텔레그램에서 /check 를 보내도 첫 줄에 버전이 나옵니다.

업데이트 순서 (5분, PC 에서)

  1. 새 ZIP 파일을 받아 압축을 풉니다.
  2. github.com → 설치할 때 만든 내 저장소(예: my-ai-company)를 엽니다.
  3. 오른쪽 위 Add file → Upload files 를 누릅니다.
  4. 압축 푼 폴더 안의 모든 파일과 폴더를 끌어다 놓습니다. 같은 이름의 파일은 새것으로 덮어써집니다.
  5. 올라가기를 기다렸다가 초록색 Commit changes 를 누릅니다.
  6. Cloudflare 가 1~2분 뒤 자동으로 새 버전을 올립니다.
  7. 아래 업데이트 기록 에서, 지금 버전과 새 버전 사이의 "해야 할 일" 을 위에서부터 차례로 합니다.
  8. 대시보드를 새로고침하고, 왼쪽 아래 버전이 새 번호인지 확인합니다. 끝!

사라지지 않는 것: 회사의 기억, 보고서, 대응 매뉴얼, 회사 소개, 로고, 텔레그램 연결, Cloudflare 에 넣은 값 5개. 모두 그대로 이어집니다. 파일만 바뀝니다.

버전을 건너뛰어도 됩니다. 예: 1.0 → 1.3 이면, 1.1 · 1.2 · 1.3 의 "해야 할 일"을 순서대로 모두 하면 됩니다. "SQL 다시 실행" 은: Supabase → SQL Editor → New query → 새 supabase/setup.sql 전체를 붙여 넣고 Run. 여러 번 실행해도 안전하고, 기존 데이터는 지워지지 않습니다.
